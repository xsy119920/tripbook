# 图片

仓库里不带照片。示例用到九张，按下面的名字放进这个目录就能出图：

| 文件 | 拍什么 |
|---|---|
| `cover.jpg` | 封面用，横构图，最好是有地标感的全景 |
| `shantou1.jpg` | 汕头老城的主图 |
| `shantou2.jpg` | 老城第二张 |
| `shantou3.jpg` | 老城第三张，傍晚亮灯后 |
| `chaozhou1.jpg` | 潮州古城主图 |
| `chaozhou2.jpg` | 古城第二张，夜景 |
| `chaozhou3.jpg` | 古城第三张 |
| `food1.jpg` | 第一样吃的 |
| `food2.jpg` | 第二样吃的 |

尺寸随意，程序会居中裁成需要的比例。**缺图不会报错**：会画成一个写着文件名的中性色块，版式不变。

自己拍的、或者有授权的图才放进来。从别处存的图只适合自己家里用，不要跟着仓库公开。
